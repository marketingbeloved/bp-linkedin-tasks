# control/ — что отдел маркетинга меняет сам, без мержа кода

Бот скачивает эту папку каждый прогон и читает её **раньше** копий, лежащих в
репозитории с кодом. Значит правка здесь действует с ближайшего прогона: мерж,
Сергей и Google Диск не нужны.

| Файл | Что задаёт |
|---|---|
| `rules.md` | лимиты: приглашения в день и за прогон, комментарии, лайки, репосты |
| `NOTE-template.md` | текст записки к приглашению (ядро в блоке ```…```) |
| `GATE-batch3-open.md` | ворота батча 3: состояние читается из ПЕРВОЙ строки |

Правила:

- **Ворота.** Первая строка со словом «ЗАКРЫТЫ» закрывает батч, любая другая —
  открывает. Удалять файл не нужно.
- **Лимиты.** Формат — таблица, как в `rules.md` репозитория. У бота есть жёсткие
  потолки в коде (приглашений не больше 20 в день, комментариев 8, лайков 15):
  цифра выше потолка не поднимет темп, она будет обрезана.
- Задания на комментарии, репосты и переписку кладутся не сюда, а в `tasks/`
  файлами `dept-*.json`.
