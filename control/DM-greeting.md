# Автоответ на приветствие в личных сообщениях

Правило Дарьи 2026-09-09: бот отвечает ТОЛЬКО на пустое приветствие
(«Hi», «thanks for connecting», «nice to connect»). Если в сообщении есть
вопрос, предложение, цена, ссылка, просьба о звонке или что-то по делу —
бот молчит, отвечает человек.

Один человек получает приветствие один раз. Текст — вежливый, короткий,
профессиональный, без продажи и без обещаний.

Меняет текст отдел маркетинга, правкой этого файла. Удалить файл = выключить
автоответ целиком.

```
Hi {Имя}, thanks for connecting. I run Beloved Pets — we're a US pet supplements brand, mostly focused on retail and the operational side of the category. Always glad to compare notes with people working the same shelf. If there's something specific you're working on, tell me and I'll come back properly.
```
