# Ворота батча 3 — ОТКРЫТЫ

Дата: 2026-09-03
Кто открыл: отдел маркетинга (Дарья)

Фото профиля Сергея приведено в порядок, стоп-условие снято. Батч 3 (246 человек)
идёт по дневной норме 20 приглашений с жёсткой недельной страховкой 100.

Пока в ПЕРВОЙ СТРОКЕ этого файла не написано «ЗАКРЫТЫ», бот считает ворота открытыми
и берёт очередь `tasks/connect-queue-batch3.json` после того, как исчерпан батч
записок v2.

**Как закрыть ворота, не трогая код.** Отдел кладёт свою копию этого файла в
репозиторий заданий — `control/GATE-batch3-open.md` в `marketingbeloved/bp-linkedin-tasks` —
и пишет в первой строке `# ВОРОТА ЗАКРЫТЫ`. Бот скачивает её каждый прогон в
`state/control/` и читает раньше этой копии. Значит открыть и закрыть батч отдел
может сам, в ту же минуту: без мержа, без Сергея и без правки кода. Раньше для
этого надо было удалить файл из репозитория, то есть снова ждать мержа.

Прежнее правило «есть файл = открыто» больше не действует: удалять ничего не нужно,
состояние читается из первой строки.
