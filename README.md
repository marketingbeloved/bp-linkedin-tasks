# bp-linkedin-tasks

Задания отдела маркетинга для LinkedIn-агента Beloved Pets.

Бот читает папку `tasks/` **по сети, на каждом прогоне**, поэтому задание начинает
работать сразу после коммита — без мержа кода и без Google Drive.

## Имена файлов

- `tasks/dept-comments-ГГГГ-ММ-ДД.json` — темы и тексты комментариев
- `tasks/dept-repost-ГГГГ-ММ-ДД.json` — репосты постов страницы

Другие имена бот не берёт: префикс `dept-` обязателен. Из нескольких файлов одного
типа выбирается самый свежий.

## Чего здесь быть не должно

Репозиторий публичный. Персональные данные сюда не кладём: имена, ссылки на профили,
переписку, списки людей для приглашений. Всё это едет через приватный репозиторий кода.
Здесь — только то, что и так публично видно в LinkedIn: тексты комментариев и подписи
к репостам.
